# 人物記事レビュー

GitHub Pages の /docs を配信し、本文と書誌の確認画面を提供します。共有用URLのフラグメントに含まれる鍵が本文の復号とコメントAPIへのアクセスに必要です。配布時は鍵が付いたURLを使用してください。

本文は段落または選択した文字範囲にコメントできます。著書一覧は書名をクリックしてコメントします。コメントは共有用URLの閲覧者間で同期されます。ログイン操作は不要です。

worker/index.js はコメント保存APIです。Sites の R2 バインディング BUCKET とランタイムシークレット REVIEW_KEY_HASH（共有鍵文字列の SHA-256）を使用します。
