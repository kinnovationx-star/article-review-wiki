# 人物記事レビュー

GitHub Pages が `docs/` を配信します。共有リンクのフラグメントに含まれる鍵で記事を復号します。ページ上部の「共有リンクをコピー」から、別の端末でも開けるURLをコピーできます。

段落、選択した文章の範囲、著書の書名にコメントできます。コメントは同じ共有リンクの閲覧者間で同期されます。閲覧・コメントにアカウントは不要です。

コメントAPIは `apps-script/` の Google Apps Script ウェブアプリです。専用のスクリプトプロパティにコメントを保存します。デプロイ時は別ファイルで `REVIEW_KEY_HASH`（共有鍵文字列の SHA-256）を設定します。
